Visual Studio · .NET 8/10 · Docker

Projekt-opsætning

Opret en Blazor Web App, forstå filstrukturen og gør projektet Docker-klar.

Sørg for at Visual Studio har workloaden ASP.NET and web development (inkl. Docker-support).

Opret projektet med skabelonen Blazor Web App. Brug .NET 8 eller .NET 10 — ældre .NET 6-guides er forældede.

Filstruktur at kende

  • wwwroot — CSS, favicon, statiske assets
  • Components/Layout — fælles layout og NavMenu
  • Components/Pages — sider med @page "/sti"
  • Program.cs — starter app, DI, routing, render modes (application lifetime)

Enable Docker fra starten når I senere deployer til Dokploy — samme vane som resten af Mercantec-stacken.
