Debug, test og usability

Debug en Blazor-client, dokumentér funktionalitet med simple tests, og kør en let usability-check.

Debug

  • Browser DevTools: Network (API-status/CORS), Console, Application
  • Visual Studio: breakpoints i @code / services (Server er nemmest)
  • Tjek response body når UI «virker tom» — ofte er det JSON-shape eller auth

Test-dokumentation

Lav en kort testplan: givne inputs → forventet UI/API-svar → faktisk resultat (screenshot/statuskode). Det dækker «dokumentér funktionalitet» uden tungt testframework først.

Usability

Simpel test: bed en kammerat om at løse én opgave (fx «find Pikachu») mens I observerer uden at hjælpe. Notér forvirring, klikfejl og manglende feedback.
