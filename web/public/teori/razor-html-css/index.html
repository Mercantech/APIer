Razor, HTML og CSS

HTML-semantik og CSS i Razor-komponenter — inkl. box model, selectors og Bootstrap til responsive layouts.

I Blazor er markup stadig HTML. Du bruger semantiske elementer (header, main, nav, section, article), lister, links, billeder og tabeller — præcis som i ren HTML, bare i en .razor-fil.

CSS i Blazor

  • Selectors — element, klasse, id, efterkommer/sibling
  • Styling — tekst, links, lister, tabeller
  • Box model — content, padding, border, margin
  • Responsive — media queries eller et framework

Bootstrap (eller MudBlazor senere) giver grid, utilities og komponenter så I hurtigt får responsive layouts uden at opfinde CSS fra bunden. Global CSS ligger typisk i wwwroot; scoped CSS kan følge en komponent som MyComponent.razor.css.
