Forms med EditForm

Indsaml brugerinput med EditForm, InputText, DataAnnotations og ValidationMessage — struktureret OOP før I poster søgninger mod OpgaverAPI.

Læringsmål

  • Opbygge forms med EditForm, OnValidSubmit og input-komponenter.
  • Validere med DataAnnotations og vise fejl med ValidationMessage.
  • Skelne mellem model-klasse og EditContext til avanceret validering.
  • Forhindre submit når data er ugyldige (min længde, required).

I Blazor samler I formularer med <EditForm>. Den kræver en model og callbacks som OnValidSubmit / OnInvalidSubmit. Det tvinger jer til tydelige typer — godt når I senere mapper til API-DTO’er.

Mini-form (min. 2 tegn)

Skriv et Pokémon-navn og submit — labben simulerer client-validering før API-kald.

@page "/soeg-pokemon"
@using System.ComponentModel.DataAnnotations
@inject IPokemonService Pokemon

<EditForm Model="form" OnValidSubmit="HandleValidSubmit" OnInvalidSubmit="OnBad">
  <DataAnnotationsValidator />
  <ValidationSummary />

  <div class="mb-3">
    <label for="q">Navn</label>
    <InputText id="q" class="form-control" @bind-Value="form.Query" />
    <ValidationMessage For="@(() => form.Query)" />
  </div>

  <button type="submit" class="btn primary">Hent fra API</button>
</EditForm>

@if (results?.Count > 0)
{
  <ul>@foreach (var p in results) { <li>@p.Name</li> }</ul>
}

@code {
  private SearchForm form = new();
  List<PokemonDto>? results;

  private async Task HandleValidSubmit()
  {
    results = await Pokemon.SearchByNameAsync(form.Query);
  }

  private void OnBad() => results = null;

  public class SearchForm
  {
    [Required(ErrorMessage = "Navn er påkrævet")]
    [MinLength(2, ErrorMessage = "Mindst 2 tegn")]
    public string Query { get; set; } = "";
  }
}

DataAnnotations

Attributter på properties: [Required], [MinLength], [Range], [EmailAddress], [RegularExpression]. DataAnnotationsValidator kobler dem til EditContext.

public class ApiKeyForm
{
  [Required, StringLength(64, MinimumLength = 8)]
  public string KeyLabel { get; set; } = "";
}

ValidationMessage vs Summary

  • ValidationMessage For="..." — felt-specifik fejl ved input
  • ValidationSummary — liste øverst i form

EditContext (avanceret)

Når I skal validere på tværs af felter (fx «slutdato efter startdato»), opret I EditContext manuelt og lytter på OnValidationRequested.

var editContext = new EditContext(model);
<EditForm EditContext="editContext" OnValidSubmit="Submit">
  ...
</EditForm>

Faldgrube: At bruge plain <input> uden InputText / @bind korrekt — EditContext opdateres ikke, og validering kører på gammel state. Brug Blazor input-komponenter eller @bind med korrekt event.

Model vs API-DTO

Form-model behøver ikke matche JSON 1:1. Map i OnValidSubmit til det DTO I sender med POST — fx opret favorit-Pokémon med kun name og id.
