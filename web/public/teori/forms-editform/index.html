Forms med EditForm

Indsaml brugerinput med EditForm, InputText og model-klasser — OOP-struktur frem for løse DOM-felter.

I Blazor samler I formularer med <EditForm>. Den kræver en model (klasse) og et callback som OnValidSubmit. Det tvinger jer til klar OOP — tungt i starten, stærkt når projektet vokser.

@page "/soeg"
@using System.ComponentModel.DataAnnotations

<EditForm Model="form" OnValidSubmit="HandleValidSubmit">
  <DataAnnotationsValidator />
  <ValidationSummary />
  <InputText id="q" @bind-Value="form.Query" />
  <button type="submit">Søg</button>
</EditForm>

@code {
  private SearchForm form = new();

  private void HandleValidSubmit()
  {
    // kald API med form.Query
  }

  public class SearchForm
  {
    [Required, MinLength(2)]
    public string Query { get; set; } = "";
  }
}
