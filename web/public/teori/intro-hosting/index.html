Intro og hosting

Hvad Blazor er, hvordan det minder om andre SPA-frameworks, og forskellen på Server, WebAssembly og Hybrid.

Blazor er Microsofts moderne web-UI-stack: du bygger genbrugelige Razor-komponenter med C#, HTML og CSS. Udvikleroplevelsen minder om React, Svelte og Vue — men logikken er C# i stedet for JavaScript.

Et Razor-komponent blander markup og C# i samme fil. Det gør det nemt at opdele UI i små, genbrugelige dele der kommunikerer med et backend Web API (som OpgaverAPI).

Tre hosting-modeller

Hvor kører koden?

Skift mellem Server og WASM — prikkerne viser trafikretning i realtid.

BrowserUI / events
ASP.NET.NET + Razor

Blazor Server

Komponenter kører på serveren. UI-events og opdateringer går over en SignalR-forbindelse. Lille download, fuld .NET på serveren — men kræver netværk for hver interaktion.

Blazor WebAssembly (WASM)

Komponenter og .NET-runtime downloades til browseren og kører lokalt. Godt til offline/CDN — men større første load, og kode er synlig for klienten.

Blazor Hybrid

Razor-komponenter i en native app (fx .NET MAUI) via WebView — ikke WASM. Adgang til native API’er, samme UI-model som web.
