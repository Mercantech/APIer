Containers · MudBlazor · async

Layout og UI-patterns

Layout-containers, UI-patterns og komponentbiblioteker — plus async i stedet for klassisk multithreading.

Layout containers i web/Blazor er typisk CSS Grid/Flex eller framework-grids (Bootstrap/MudBlazor). Vælg kontroller der matcher kravet: knapper, tabeller, dialoger, forms.

UI design patterns I møder ofte: Master/Detail, List + filter, Wizard, Modal confirm. Implementér dem som egne komponenter.

MudBlazor

MudBlazor er et open-source komponentbibliotek til Blazor (knapper, tabeller, dialogs, themes). Det speeder UI op uden at I tegner alt fra scratch — se mudblazor.com.

«Multithreading» i Blazor

I web-UI er svaret næsten altid async/await (Task) til I/O (API-kald), ikke manuelle threads. Undgå at blokere UI-tråden. Task.Run bruges sjældent i WASM og kan være forkert på Server — start med async HttpClient.
