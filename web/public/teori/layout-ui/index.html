Layout og UI-patterns

Layout-containers, Master/Detail, list+filter, MudBlazor — og hvorfor async/await er «trådning» i moderne Blazor.

Læringsmål

  • Implementere Master/Detail over API-data (Pokémon-liste + detail).
  • Vælge mellem CSS grid, Bootstrap og MudBlazor til layout.
  • Forklare async I/O vs Task.Run / manuelle threads i UI.
  • Genkende Wizard, Modal confirm og List+filter patterns.

Layout containers strukturerer siden: sidebar + content, topnav + main. I undervisningen kombineres ofte Bootstrap grid med komponent-opdeling.

Master/Detail

Venstre liste (master) vælger id; højre panel (detail) henter /go/pokemon/{id} eller viser cached DTO. State (selectedId) bor i parent — child får parametre.

<div class="row">
  <div class="col-md-4">
    <PokemonList Items="mons" OnSelect="id => selectedId = id" />
  </div>
  <div class="col-md-8">
    @if (selectedId is int sid)
    {
      <PokemonDetail Id="sid" />
    }
  </div>
</div>

List + filter

Søgefelt + @bind på filterstreng; enten client-side LINQ på hentet liste eller debounced API-kald. LoL-champions med rolle-filter er klassisk eksamen-case.

MudBlazor

MudBlazor leverer MudTable, MudDialog, MudTextField, theming. Install NuGet, tilføj i Program.cs:

builder.Services.AddMudServices();

Wrap layout med MudThemeProvider, MudPopoverProvider, MudDialogProvider. Godt når I vil matche moderne admin-UI uden at skrive al CSS selv — se mudblazor.com.

Async — ikke threads i UI

Web-UI venter på netværk. await Http.GetFromJsonAsync frigiver tråden så Server-circuit kan betjene andre events. Task.Run flytter CPU-arbejde til thread pool — sjældent brugt til API-kald; på WASM begrænset.

Async-tidslinje (UI)

Se forskellen på await (responsiv UI) vs blokering.

  1. Event: «Hent Star Wars personer»
  2. UI viser spinner (state)
  3. await Http — andre klik kan stadig queues (Server)
  4. Resultat bindes til MudTable / HTML table
  5. Spinner skjules

Faldgrube: .Result eller .Wait() på async Task i UI — deadlock/race på Blazor Server. Brug async hele vejen.

Modal confirm

Slet favorit? MudDialog eller simpel conditional render + fokus-trap. Bekræft før DELETE mod API.
