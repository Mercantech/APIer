Sikkerhed og performance

Clientside-risici (XSS m.m.), SPA-tokens og performance-tips for Blazor/WASM.

Sikkerhed

  • XSS — stole ikke på brugerinput i HTML. Blazor encoder som udgangspunkt; pas på MarkupString / rå HTML.
  • API-nøgler — elev-nøgler er personlige. Gem ikke secrets i public git. Brug headers (X-Api-Key), ikke query-strings.
  • SPA-tokens — access tokens i memory/session er at foretrække frem for long-lived keys i localStorage. Forstå CORS og at alt i browseren kan inspiceres.
  • WASM — klientkode kan reverse-engineeres; hemmelig business-logik hører hjemme på serveren.

Performance

  • Minimer unødige re-renders; brug parametre bevidst
  • WASM: trim, compression, undgå store unused packages
  • Lazy-load tunge sider; paginér API-svar (katalogets demos trimmer ofte arrays)

Læs hos Microsoft

  • Blazor security
  • Host and deploy WASM

Prøv med API

  • Opret en nøgle under kataloget og kald LoL — bemærk at nøglen aldrig skal committes.
