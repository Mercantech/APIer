HttpClient og API-kald

Kald OpgaverAPI asynkront med HttpClient — CRUD over HTTP, DTO’er, typed clients og robust fejlhåndtering.

Læringsmål

  • Mappe CRUD til HTTP-metoder mod REST API.
  • Bruge GetFromJsonAsync, PostAsJsonAsync med DTO/records.
  • Håndtere HttpRequestException, statuskoder og tomme svar.
  • Registrere typed HttpClient i Program.cs (se DI-lektion).

CRUD over HTTP: POST create, GET read, PUT/PATCH update, DELETE delete. I Blazor er kaldene async — UI-tråden blokeres ikke mens I venter på Pokémon-JSON.

Async-tidslinje

Se rækkefølgen: UI viser loading → await HTTP → UI opdateres med resultat.

  1. Bruger klikker «Hent Pokémon»
  2. loading = true (render)
  3. await GetFromJsonAsync — tråd frigives
  4. JSON deserialiseres til List<PokeDto>
  5. loading = false, liste vises
@page "/pokemon"
@inject HttpClient Http

<button @onclick="Load" disabled="@loading">Hent Pokémon</button>
@if (loading) { <p>Henter…</p> }
@if (error is not null) { <p class="err">@error</p> }
@if (items is not null)
{
  <ul>@foreach (var p in items) { <li>@p.Name</li> }</ul>
}

@code {
  List<PokeDto>? items;
  bool loading;
  string? error;

  async Task Load()
  {
    loading = true;
    error = null;
    try
    {
      items = await Http.GetFromJsonAsync<List<PokeDto>>("/go/pokemon?limit=20");
    }
    catch (HttpRequestException ex)
    {
      error = $"API fejl: {ex.StatusCode}";
    }
    finally { loading = false; }
  }

  public record PokeDto(string Name, int Id);
}

DTO og JSON-shape

Property-navne skal matche JSON (case-insensitive default). Brug [JsonPropertyName("id")] ved behov. Records er gode til read-only API-data.

public record ChampionDto(string Id, string Name);

// Explicit check
var response = await Http.GetAsync("/LeagueOfLegends/Champions");
if (!response.IsSuccessStatusCode)
{
    var body = await response.Content.ReadAsStringAsync();
    throw new InvalidOperationException($"{response.StatusCode}: {body}");
}
var champs = await response.Content.ReadFromJsonAsync<ChampionDto[]>();

X-Api-Key og headers

using var request = new HttpRequestMessage(HttpMethod.Get, "/LeagueOfLegends/Champions");
request.Headers.Add("X-Api-Key", apiKey);
var response = await Http.SendAsync(request);

Bedre: encapsuler i ILolService så komponenter ikke kender header-detaljer.

Typed client

builder.Services.AddHttpClient<IPokemonApi, PokemonApi>(c =>
    c.BaseAddress = new Uri("https://api-opgaver.mercantec.tech"));

Faldgrube: At læse JSON ind i dynamic eller JsonDocument overalt — det skalerer dårligt. Definér DTO’er; fang mismatches tidligt med tests eller tydelige fejl i UI.

Faldgrube: Glemt trailing slash i BaseAddress + absolute path — dobbelte eller manglende slashes giver 404. Følg én konvention (base med slash, relative paths uden leading slash).
