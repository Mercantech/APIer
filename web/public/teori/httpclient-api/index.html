HttpClient og API-kald

Kald OpgaverAPI asynkront fra Blazor med HttpClient — CRUD over HTTP i stedet for jQuery AJAX.

CRUD over HTTP mapper til POST / GET / PUT / DELETE. I Blazor bruger I HttpClient (gerne via DI), ikke new HttpClient() overalt i produktion.

@page "/pokemon"
@inject HttpClient Http

<button @onclick="Load">Hent Pokémon</button>
@if (items is not null)
{
  <ul>@foreach (var p in items) { <li>@p.Name</li> }</ul>
}

@code {
  List<PokeDto>? items;

  async Task Load()
  {
    items = await Http.GetFromJsonAsync<List<PokeDto>>("/go/pokemon?limit=20");
  }

  public record PokeDto(string Name, int Id);
}

Beskyttede endpoints (fx LoL) kræver header X-Api-Key — opret nøgle via kataloget når I er logget ind.

Http.DefaultRequestHeaders.Add("X-Api-Key", apiKey);
var champs = await Http.GetFromJsonAsync<ChampionDto[]>("/LeagueOfLegends/Champions");

Registrér HttpClient i Program.cs med korrekt BaseAddress (fx https://api-opgaver.mercantec.tech) — se Microsofts guide om typed clients / IHttpClientFactory.
