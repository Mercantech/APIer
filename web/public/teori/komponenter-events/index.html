Komponenter og events

Byg UI af genbrugelige komponenter med parametre, two-way binding og EventCallback — parent/child-flow som Pokémon-liste der vælger detail.

Læringsmål

  • Definere [Parameter] og forældre/child-kommunikation.
  • Bruge @bind og @bind-Value:after til two-way data.
  • Implementere EventCallback til events opad (valgt champion).
  • Sammenligne Blazor-events med jQuery/DOM-manipulation.

Komponenter er Blazors byggeklodser. En fil = én komponent (typisk). Parent sender data ned; child notifier op via callbacks.

Parametre og EventCallback

@* PokemonCard.razor *@
<div class="card" @onclick="OnSelect">
  <h3>@Name</h3>
  <p>#@Id</p>
</div>

@code {
  [Parameter] public string Name { get; set; } = "";
  [Parameter] public int Id { get; set; }
  [Parameter] public EventCallback<int> Selected { get; set; }

  private async Task OnSelect() => await Selected.InvokeAsync(Id);
}
@* PokemonList.razor (parent) *@
@foreach (var p in mons)
{
  <PokemonCard Name="@p.Name" Id="@p.Id" Selected="OnPick" />
}
<p>Valgt id: @selectedId</p>

@code {
  int? selectedId;
  List<Mon> mons = ...;

  private Task OnPick(int id)
  {
    selectedId = id;
    return Task.CompletedTask;
  }

  record Mon(string Name, int Id);
}

@bind dybere

@bind-Value="text" er syntaks-sukker for value + ValueChanged + ValueExpression. Til delayed API-søgning kan I bruge @bind-Value:after="Search" (.NET 8+) så søgning kører efter opdatering.

<input @bind="filter" @bind:event="oninput" />

@bind:event="oninput" opdaterer ved hvert tastetryk (default er often onchange ved blur).

C# vs JavaScript

  • Objekter & klasser — stærke typer på parametre
  • Events — @onclick, @onchange; stop propagation med @onclick:stopPropagation
  • DOM — undgå manuel query; beskriv UI fra state
  • JS interop — IJSRuntime når browser-API mangler

Faldgrube: At mutere child’s [Parameter] direkte i child — one-way flow ned, events op. Parent ejer sandheden om selectedId.
