Komponenter og events

Byg UI af genbrugelige komponenter med parametre, data binding og C#-events — i stedet for jQuery-DOM.

Komponenter er Blazors svar på «custom controls». I sender data ind med [Parameter], reagerer på klik med @onclick, og binder felter med @bind.

@* PokemonCard.razor *@
<div class="card" @onclick="OnSelect">
  <h3>@Name</h3>
  <p>HP: @Hp</p>
</div>

@code {
  [Parameter] public string Name { get; set; } = "";
  [Parameter] public int Hp { get; set; }
  [Parameter] public EventCallback<string> Selected { get; set; }

  private async Task OnSelect() => await Selected.InvokeAsync(Name);
}

C# vs JavaScript

  • Objekter & klasser — stærke typer, properties, interfaces
  • Funktioner — metoder med klare parametre/returtyper
  • DOM — Blazor opdaterer UI via render; I skriver sjældent document.querySelector
  • JS interop — kun når browser-API’er mangler i .NET (fx special-clipboard, canvas)

jQuery/AJAX erstattes af komponent-state + HttpClient. Det er den praktiske vej til «clientside der taler med Web API».
